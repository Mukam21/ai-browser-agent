AI Browser Agent - Автономный агент для браузера

Автономный AI-агент, который управляет браузером для выполнения сложных задач через текстовые команды.

Быстрый старт


``bash
    # 1. Установи Go 1.21+
    # 2. Клонируй проект
    git clone https://github.com/yourname/ai-browser-agent.git
    cd ai-browser-agent

    # 3. Установи зависимости
    go mod tidy

    # 4. Настрой API ключ (попроси у рекрутера)
    # Windows:
    set OPENAI_API_KEY=sk-твой_ключ
    # Linux/Mac:
    export OPENAI_API_KEY=sk-твой_ключ

    # 5. Запусти
    go run cmd/agent/main.go
``

Особенности
✅ Полная автономность - агент сам планирует действия
✅ Без хардкода - нет предзаданных шагов или селекторов
✅ ReAct архитектура - думает → действует → наблюдает
✅ Безопасный режим - работает даже на Windows с антивирусом
✅ Управление контекстом - помнит историю действий

 Архитектура
`` text
    Пользователь → AI Агент → Планирование (LLM) → Браузер → Результат
``

Агент умеет:

Анализировать страницы

Находить элементы по описанию

Кликать, вводить текст, скроллить

Делать скриншоты

Адаптироваться к новым сайтам

Технологии
Язык: Go 1.21+

AI: OpenAI GPT-4o / GPT-4o-mini

Архитектура: ReAct (Reasoning + Acting)

Браузер: Безопасный режим + Rod (при возможности)
